Complete 4-Pranayama 3D Sanctuary Guide

Classical Hatha Yoga Sadhana: Awaken, Purify, Deepen & Meditate

1. Nadi Shodhana

Alternate Nostril Breathing: Uses Vishnu Mudra (right thumb & ring finger) to alternate breathing between Ida Nadi (Left / Lunar cooling channel) and Pingala Nadi (Right / Solar warming channel), balancing both cerebral hemispheres.

2. Ujjayi Pranayama

The Victorious Ocean Breath: Gently constrict the glottis at the Vishuddha (Throat) Chakra to create a soft, sibilant ocean wave sound ("Haaaa") with lips closed, expanding the lungs and calming the vagus nerve.

3. Bhramari Pranayama

The Humming Bee Breath: Apply Shanmukhi Mudra to gently close the ears and senses, inhale through the nose, and exhale with a steady nasal hum ("Mmmmmm") that vibrates the paranasal sinuses, pineal gland (Ajna), and crown.

4. Bhastrika Pranayama

The Blacksmith's Bellows: Pump the lungs and diaphragm rapidly with equal force on both inhalation and exhalation to fan Manipura Agni (solar plexus fire), followed by a deep recovery inhale and Maha Bandha retention.

Option 2: Build Standalone Pranayama3D.apk (Capacitor CLI)

Run these commands in a folder containing your downloaded index.html to compile a native Android .apk binary: 

mkdir pranayama-apk && cd pranayama-apk
mkdir www && cp ../index.html www/index.html
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Pranayama 3D Sanctuary" "com.sanctuary.pranayama3d" --web-dir www
npx cap add android
npx cap copy android && cd android && ./gradlew assembleDebug
